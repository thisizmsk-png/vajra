# Core Rust tests that run in their own serial pass (ci/run-tests.sh), not alongside the other ~1,300 in parallel.
# Each one has a time limit or a lock that other tests' processes can crowd out on a loaded machine. Running it alone
# keeps every assertion and every limit as written: nothing here is skipped, retried or loosened.
#
# One exact test name per line, or a module path ending in "::" for every test under it. A name that no longer matches a
# test fails the run, so the list cannot rot. Remove an entry once its test is fixed to hold under parallel load.
