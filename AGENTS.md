# Instructions for agents working in this repository

The rules for agents are in CLAUDE.md at the top of the repository. Read it first. In short:

## Review comments

In PR reviews, review comments and messages, name files in plain words with no slash, for example "runproto.rs in the desktop core". Never paste paths, globs, brace words or two-dot ranges. If the guard blocks a comment, reword it once with the folder described in words and post it again.
